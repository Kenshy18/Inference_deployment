# 05 — Slate

**Direction: sober modern broadcast tool.** Premiere Pro の実務 UI を今日ゼロから作り直したらこうなる、という想定。寒色寄りニュートラル 3 段のサーフェス、境界線は「コントロールに輪郭が必要な場所」だけ、アクセントは彩度を落とした steel blue 1 色を機能的にのみ使用。ラウンド 1 で却下された装飾（グラデーション、グロー、大型数字、アンバーのタイムコード演出）は全廃した。

## Rationale

1. **分離はサーフェス段差で行う。** キャンバス `#131518` の上にパネル `#191C21` が浮き、その上の操作対象（フローノード、タイムラインセル、LIVE メタセル）が `#1F232A`、計器類・入力・コンソールは一段沈む well `#14161A`。ヘアライン `rgba(200,215,235,.08)` は入力の輪郭・セクション区切り・メトリクスストリップ上端など、実際に境界が要る場所に限定。パネルヘッダは面の上のタイポだけ(バー無し・罫線無し)で、4 変種の中で最も静かなパネルクロームになる。
2. **状態表現は 3 手段のみ**: 2px エッジマーカー(処理中のキュー行の左端)、小さな solid バッジ(qbadge / sec-badge)、テキスト色。面をアクセント色で塗るウォッシュは使わない。プログレスはすべてフラット単色 `#4D7FB8`・3〜4px。
3. **スコープは放送機材の文法。** 6 面のハードウェアスコープは同一のトレース色 `#647E9C`(データ色。アクセントとは別トークン)で統一し、色数を増やさずに「計器の壁」を作る。軸注記(`peak 23.9` / `scale 100%` / `180 pt`)は 9.5px の mono。VRAM / MEMORY には仕様上「計算済みだが未表示」の絶対値 (`24.9 / 32 GB`, `26.2 / 64 GB`) を軸行に表示した。同様に、予測器が計算している残り時間を `予測残り 07:20` として ETA 列に追加(いずれも ui-spec §4.1c / §4.1d で fair game と明記されたデータのみ)。

## UX-presentation changes vs. current app

- パネルヘッダのバー背景・境界線を撤去し、10px の EN マイクロキャップだけに(Source / Monitor / Inspector / Console)。
- フローノードは raised カード + 6px 状態ドット + 3px ミニバーに整理。完了はグレー、実行中のみアクセント。コネクタは 1px ヘアライン。
- kbd チップを廃止し、ショートカットはツールチップ (`^↵` 等の表記もツールチップ内のみ)。
- LED 風グロー・スキャンライン・シマー等の演出を全廃。LIVE バッジも静的な solid チップ。
- キュー処理中行は左 2px アクセントエッジ + 下辺 3px フラットバーで表現(面のティントなし)。
- Inspector は実行中のため全コントロール disabled (透明度 55%)。簡単/詳細トグルとセクション開閉はモック上で操作可能。**注意: 実機仕様では簡単/詳細トグルも処理中は無効** (ui-spec §5)。状態デモのため意図的に操作可能にしており、トグルにツールチップ `実機では処理中は無効` を付けて明示した。

## 業務ソフト感の根拠

装飾で「プロ用らしさ」を演出するのではなく、実務ソフトが実際に持っている性質だけで構成した:

1. **色の規律。** 画面上の有彩色は (a) 実行中を示す steel blue、(b) 完了を示す緑のテキスト、(c) 停止ボタンの muted red、の 3 系統だけ。それ以外は全て同一色温度のグレー。アクセントが出現する場所は「選択・実行中・進捗・フォーカス」に厳密に限定されるため、色を見るだけで状態が読める — これは Resolve や Premiere が実際に採っている契約であり、テーマではなく情報設計。
2. **計測に基づく整列。** 96px 固定のラベル列、26px のコントロール高、4px グリッドの余白、右端揃えの数値列(フェーズグリッドの % とカウント、ETA 列、スコープ現在値)。数値は全て tabular-nums で桁が揺れない。静かなデザインは精度でしか成立しないため、列のズレ・高さの不揃いを 2 回のスクリーンショット検証で潰した。
3. **データがヒーロー。** 最大の面積を占めるのは 6 面のハードウェアスコープと 12 行の生ログであり、どちらも実在のテレメトリ形式 (`[inference] [progress] processed=…`) をそのまま表示する。飾りの数字がひとつもなく、最大の数字でも 20px(45.8% 全体進捗)。
4. **クロームの沈黙。** パネルヘッダは面上のタイポのみ、境界はサーフェス段差、影ゼロ、モーションは実行中ドット 1 個。ソフトウェア自身が主張せず、作業対象(キュー・進捗・ログ)だけが前に出る — 「毎日 8 時間開いているツール」の顔。

## Self-verification

2 回の full build→screenshot→review イテレーション + 状態プローブ(LIVE タブ / 詳細ビュー / セクション折りたたみ)。修正項目: `[hidden]` を上書きしていた display バグ(両タブ同時描画)、コンソール 12 行目の欠け、左ペインのサブヘッダ折返し、キュータイトルの過剰トランケート、KF間隔列の単位はみ出し。最終ショットは 1920 / 1366 とも overflow 警告なし。

### Round 2 director pass (fix log)

- **詳細ビューの完全化** (critical): 後処理に `性器後処理 — 構成` (パイプラインJSON / クラス別スコアJSON / 形状・KF・補完 = クラス別GUI / クラス別ルール 4 列エディタ + `＋ クラスを追加`)、`楕円近似（K2）` 10 行、`互換出力`、`顔後処理 — 追跡・プライバシーマスク` 7 行、`専門設定` を追加。オーバーレイに `旧形式の追加オーバーレイ（任意）`、`目キーポイント下限`、`FFmpeg実行ファイル`、`専門設定` を追加。簡単専用の クラス別形状・キーフレーム minitable は `.simple-only` で 詳細では非表示 (エディタに置換)。
- **タイポ/グリッドのトークン化**: 9 段あったフォントサイズを `--fs-ui/--fs-sec/--fs-micro` の 3 トークン + readout に統合。7/9/5px 等のオフグリッド余白を 4px グリッドへ正規化。パネルヘッダ高を 32px に統一。チェックボックスを 16px に。
- **色規律**: コンソールの stage タグを accent (`--acc-tx`) → data トークン (`--trace`) へ。データを運ぶ副次テキストに `--t2b` (≈4.5:1) を導入。
- **スライダー**: gradient トラックを廃止し、フラット 2 分割 (well トラック + accent 塗り + 12px サム) の静的 div に変更 — round 2 の「gradient 全面禁止」対応。
- **実行中ノード**: キュー処理中行と同じ 2px 左エッジマーカーを `fnode.is-active` にも適用 (状態語彙の統一)。
- **1366 対応**: scopes `grid-auto-rows:minmax(72px,1fr)`、コンソール行を `clamp(168px,24vh,236px)` に。コンソールは追従 on のため末尾へスクロールした状態で表示。
- **詳細ビューの横はみ出し 2 件** (性器の描画データ seg / 線幅 numun) を検出・修正 (`.field.num.sm` 44px、grow seg は content-basis + ellipsis 退避)。プローブで全 seg ボタンの clipping ゼロ、Inspector `scrollWidth == clientWidth` を確認。
- 簡単/詳細トグルは実機では処理中無効だが、デモ操作のため有効のまま (上記注意書きとツールチップで明示)。
