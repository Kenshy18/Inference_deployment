# 06 — Carbon

**Direction: industrial DCC workstation.** Nuke / Flame / Baselight の系譜。4案中で最も暗く、最も高密度。
装飾ではなくエンジニアリングで成立させる: フラットなカーボン色のスラブをヘアラインだけで区切り、
データはすべて等幅、色は「選択・アクティブ・実行中」を示す鈍い工業オレンジ 1 色のみ。
影ゼロ、グラデーションゼロ、モーションはステータスバーの実行中ドット 1 個の減光パルスのみ。

## Rationale

- **スラブ + ヘアライン。** Round 1 の「浮いたカードとグロー」を全廃し、パネルは背景に密着した
  フラット面。すべての境界は 1px の `rgba(255,255,255,.07)`。面のステップは bg / panel / raised の
  3 段だけで、同一色温度のニュートラルグレー。
- **アクセントの規律。** `#C4763B`(工業オレンジ) が現れるのは: アクティブタブ下端の 2px、実行中
  キュー項目の左 2px エッジ + 進捗、アクティブなフローノードの上端 2px、実行中フェーズの 3px バー、
  選択済みセグメント / チェック、プライマリボタン(実行; 本状態では停止=danger に置換)、
  ステータスの「実行中」。それ以外は完全にグレースケール。semantic 色 (ok/err/info) は
  バッジ文字・停止ボタン・ログのステージタグに限定。
- **モノスペース優先のデータ組版。** 数値・パス・ID・ログ・キュー meta・スコープ値はすべて等幅 +
  `tabular-nums`。UI 12px / マイクロラベル 9.5px 大文字 (+0.06em 統一, 英語のみ — 日本語には字間を
  かけない)。ヘッダ・行はすべて 24px、コントロール外形は 22px (トップバーの transport ボタンのみ
  24px)、パディング 6–10px で 4 案中最高密度。
- **スコープは計器。** 6 個のテレメトリスコープは単色 1.25px トレース + フラット 7% 面のみ。
  凡例なし (ラベルが系列名)、グリッドは 5% の 3 本。座標系は viewBox 0–180 とデータ終端を一致。
  運用者が実際に注視する FPS のみ輝度を 1 段上げた `#A8A8AD` (色相追加なしの焦点付け)。
  VRAM / MEMORY の軸には仕様上未表示だった実容量 (`24.9 / 32.0 GB` 等) を表示 —
  数字が増えるほど業務機材に見える、の方向で採用。
- **メーターは静かなバー。** 進捗はすべて 3px の単色ソリッド (実行中=オレンジ、完了=白 10%)。
  完了状態はチェックアイコンと文字色が担うため、バーはオレンジ 1 本だけが目立つ。
  ティック・セグメント・シマーなし。
- **busy 中のアクセント抑制。** Inspector が減光されている間は選択済みセグメント / チェック /
  スライダの塗りを `#3F3F45` へミュート。オレンジは操作可能になった時に戻る — 画面上のオレンジは
  常に「実行中マーカー + 操作可能な選択」だけを意味する。

| accent | `#C4763B` (ink `#150D07`) | 選択・アクティブ・実行中・primary のみ (busy 中の選択塗りは `#3F3F45` へミュート) |

| rhythm | 4px グリッド; ヘッダ・行 24px; コントロール 22px (transport のみ 24px); pad 6–10px; bar 3px | 密度 = 個性 |
| layout | console 168px; ペイン間 / コンソール上に 6px ドラッグシーム (panel 色で視覚コストゼロ) | リサイズ契約の予約 |

サムネイル / LIVE プレビュー内の微弱なモノクロ陰影は「動画コンテンツのプレースホルダ」であり
UI クロームではない (壊れた画像枠や絵文字を出さないための最小表現)。

## UX-presentation changes vs current app

- カード浮遊 + ラジアルグロー → フラットスラブ + ヘアライン。角丸 10px → 3px。影全廃。
- 青アクセント + amber running の 2 色制 → 単一オレンジの「状態マーカー」制。状態は 2px エッジ /
  3px バー / テキスト色でのみ表現し、面のウォッシュ (amber 行背景など) を排除。
- スコープ 6 色トレース → 単色計器。ラベルが識別を担うため色分けは冗長と判断。
- 未表示データの表面化: VRAM / RAM の実容量を軸ラベルに表示 (spec §4.1c で許可された範囲)。
- キュー meta は実アプリ同様 2 行クランプ。フロー 6 ノードは 1 本のスラブをヘアラインで 6 分割し、
  「パイプライン=1 本の機械」として読ませる。

## 業務ソフト感の根拠

1. **情報が主役で、様式が消えている。** 画面上の非データ装飾はゼロ。1920 のスクリーンショットに
   写るのは数値・ラベル・計器・ログだけで、視線を引く要素は「実行中」を示すオレンジのマーカー
   のみ。これは Nuke / Flame が 10 時間運用に耐える理由と同じ構造。
2. **規律 = 品質の証明。** 全コントロール外形 22px (transport のみ 24px) の統一、96px 固定のラベル列、4px グリッド、
   等幅 + tabular-nums による桁の縦揃え、日本語に字間をかけない、など「measure してある」ことが
   一目で分かる精度で信頼感を作る。派手さで隠せない分、揃っていること自体が仕上げ。
3. **状態表現が運用者向け。** 実行中は: 停止ボタンが実行を置換、Inspector 全コントロールが
   減光 + 選択塗りミュート、出力リポジトリの「処理中は変更できません」ヒント、キュー行の 2px
   エッジ、HUD / ステータスバーの実行中表示、と冗長系で伝える。色のウォッシュではなくエッジと
   テキストで示すため、長時間注視しても疲れない。
4. **計器室のメタファ。** スコープは装飾のない単色オシロ、進捗は 3px の平坦なバー、タイムラインは
   井桁のセル。すべて「読むための器具」であり「見せるためのグラフィック」ではない。

## Self-verification

3 回の build → screenshot → 自己批評サイクル。修正内容: (1) フレキシブルスコープが 440px に
膨張して空虚に見える問題 → 上限 380px + フェーズグリッドへの余白吸収 + フラット面フィル追加;
タブの大文字化; meta 2 行クランプ。 (2) LIVE プレビューが黒一色の虚無 + マスク枠にアクセント色
誤用 → 輝度を持つモノクロフレームへ、枠色は neutral / info に修正。 (3) 詳細ビューの
クラス別ルール表が「ポ / 楕」と略されていた fidelity 違反 → 実ラベル「ポリゴン / 楕円」を
コンパクト組版で復元、ヘッダ折返し修正。1920 / 1366 とも overflow 警告なし。

## Round 2 director fixes

全 15 項目を適用 (critical 1 / major 3 / minor 11、スキップなし):

コントロール外形 22px / ヘッダ・行 24px へ整列; busy 中の選択塗りミュート; 字間 .06em 統一;

duration チップ 9.5px; busy-note 帯を削除 (リポジトリヒント + 減光が担う); 完了バー白 10%;
chip 境界を `--hair` へ; インラインstyle を `.wide` / `.pair` / `:disabled` 規則へ回収;
console 168px + 6px ドラッグシーム挿入 (panel 色で不可視)。
