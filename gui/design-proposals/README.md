# Design Proposals — Mask Pipeline Studio

現行GUI(`gui/src`)には一切手を加えず、**見た目とUX表現のみ**を刷新する4つの独立したデザイン案。
各案は完全自己完結の静的モック(`index.html` をブラウザで開くだけで動作、タブ切替・セクション開閉・簡単/詳細トグルつき)。
4案はすべて同一のアプリ状態(`_shared/ui-spec.md` の SHARED SAMPLE STATE)を描画しており、条件を揃えて比較できる。

| 案 | 名前 | 方向性 | キーカラー |
| --- | --- | --- | --- |
| [01-graphite](01-graphite/) | **Graphite Console** | DaVinci Resolve / Blackmagic機材系。漆黒グラファイトの計器盤。フラット・高密度・精密 | 黒鉛 `#0A0A0B` + アンバー `#E8A44F` |
| [02-horizon](02-horizon/) | **Horizon** | モダンAdobe / Frame.io系。シネマティックな青の深度、タイムライン風パイプライン表示 | 群青 `#0F1218` + ブルー `#4C8DFF` |
| [03-atelier](03-atelier/) | **Atelier** | 温かい漆黒+シャンパンゴールド。余白とセリフ数字で魅せる「静かな高級感」 | 暖黒 `#141210` + シャンパン `#C9A86A` |
| [04-prism](04-prism/) | **Prism** | Linear / Raycast系。ガラス質のレイヤー、菫色の環境光、抑制された1本のグラデーション | 紫黒 `#0E0E13` + バイオレット `#8B7CFF` |

## 各フォルダの内容

- `index.html` — モック本体(外部リソース依存ゼロ)
- `NOTES.md` — デザイン意図・トークン表・現行UIからの表現変更点
- `shot-1920.png` / `shot-1366.png` — 1920×1080 / 1366×900 のスクリーンショット

## 制作プロセス

1. `_shared/ui-spec.md` — 実ソース(App.tsx / 全コンポーネント / defaults.ts / job-manager.ts 等)から抽出したUI棚卸しと共通サンプル状態
2. `_shared/DESIGN_GUIDELINES.md` — 4案共通の制約(機能変更禁止・忠実性・品質基準)
3. 案ごとに 構築 → `_shared/screenshot.mjs` でスクリーンショット → 自己批評 のループ(最低2周)
4. デザインディレクター役による批評 → 修正反映
5. 4案横断の網羅性監査(必須リージョン・正確なラベル・同一サンプル状態・機能の捏造なし)

## 制約(全案共通)

- 機能の追加・削除・変更なし。実アプリに存在するコントロールのみを描画
- ラベルは実アプリの文言をそのまま使用(推論 / 後処理 / オーバーレイ / 実行環境 …)
- ダーク専用(プロNLEの慣習として意図的な選択)
- 外部リクエストゼロ(Webフォント・CDN・画像ファイル不使用)
