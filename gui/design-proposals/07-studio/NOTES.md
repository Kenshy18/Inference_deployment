# 07 — Studio（reference-grade neutral）

## Rationale

Studio は「基準器」としてのニュートラルです。DaVinci Resolve / Fairlight 世代の成熟した商用スイートが実際にやっている抑制だけで構成しました。サーフェスは完全無彩色の3段階（#121212 / #1A1A1A / #222222）で、色相キャストはゼロ。分離はヘアライン（白 7.5%）と1段のサーフェス差の併用 — Resolve のパネルと同じ文法です。アクセント #6C87A6（減彩ブルーグレー）は機能にのみ現れます：アクティブタブの2pxアンダーライン、処理中アイテムの2pxエッジマーカー、選択セグメントの塗り、進行中のフラット単色プログレス、フォーカスリング。それ以外の全ピクセルはグレースケールで、semantic 色（success/warn/danger も減彩）はバッジ・状態ドット・停止ボタンの輪郭にしか使いません。

タイポグラフィのルート指定は 13px/1.45 ですが、実効の UI 基準サイズは 12px です（ラベル・コントロール・チップ）— 中庸密度のクロームを1段引き締めるための意図的な運用基準として明記します。meta・ヒントは 11px、EN マイクロラベルのみ 10px uppercase +0.06em（日本語には一切レタースペーシングなし）、計測値は等幅 tabular の 13px（現在値・経過/予測）と 20px（全体進捗の1箇所のみ）。数値・パス・ログは等幅 + tabular-nums で、等幅スタックには "Noto Sans JP" フォールバックを持たせ、混植文字列（`4本 · 残り2` 等）でも字形が崩れません。グラデーション・グロー・ガラス・装飾アニメーションはゼロ（唯一の動きはステータスバーの実行中ドットの微弱な opacity パルス、`prefers-reduced-motion` で停止）。影も使いません — 影が許されるのはポップオーバーだけという規則で、このモックにポップオーバーは常設されないため実質フラットです。ハードウェアスコープは6面とも同一のニュートラルグレー1pxトレース＋微弱な面塗り。ラベルと現在値が識別を担い、色は何も主張しません。「UI は作業の背後に消える」が本案の人格です。

密度は中庸バランス型：行高 ~25px、パディング 8–10px、角丸 5px 一種のみ。1920×1080 と 1366×900 の両方で全フェーズグリッドまで収まるよう、スコープ高だけをブレークポイントで可変にしています（72 / 56 / 38px）。

## UX-presentation changes vs current app

- **状態表現の置換**：アンバーの「実行中」ウォッシュを廃止し、処理中キュー行は「1段のサーフェス上げ + 2px アクセントエッジ + 小バッジ + 底辺2pxフラットバー」に。状態はエッジとテキストで示し、面では示しません。
- **スコープの無彩色化**：6色だったトレースを単一ニュートラルに統一（各スコープはラベル+現在値で識別）。VRAM / MEMORY の軸には未表示だった実測値 `24.9 / 32.0 GB` / `26.2 / 64.0 GB`、GPU 軸には `RTX 5090` を表出（spec §4.1c の "not currently rendered — surface if you want" 領域）。
- **全体進捗の脱ヒーロー化**：巨大数字をやめ、20px の tabular `45.8%` + サマリ + 4px フラットバー + 経過/予測の2セルに整理。
- **フローノードの精密化**：番号/アイコン/ラベル/値/ミニバーを 36px インデントの2行グリッドに揃え、コネクタは1pxライン。アクティブのみボーダーがアクセント化。
- **kbd チップ廃止**：ショートカットはツールチップ内テキストへ（`キューを順番に処理 (Ctrl+Enter)` 等）。
- **タブは Resolve 文法**：STATUS / LIVE は 10px UC + 2px アクセントアンダーラインのみ。

## 業務ソフト感の根拠

装飾なしでプロツールに見える理由は次の4点に集約しています。

1. **精度が唯一の贅沢**：全コントロール高 24px、ラベル列 96px 固定、8/12px の間隔リズム、右揃え tabular 数値、1px 統一ボーダー。静かなデザインはズレが即座に露呈するため、列・行・ベースラインを測って揃えています（フローノードの値行インデント、srow の1行収まり、コンソールのガター幅まで）。
2. **色が意味論として機能**：画面上のブルーグレーを見た瞬間「今どこが動いていて、何が選択されているか」が分かる。色数を絞ったのではなく、色に職務を与えた結果としての無彩色です。
3. **実データの流儀**：`h264_nvenc`、`cuda:0`、`[progress] processed=6480/14400`、`RTX 5090 · scale 100%`、`180 pt` — 計測器としての正直な表示形式は、飾られたダッシュボードではなく毎日使う道具の言語です。
4. **クロームの消灯**：パネルタイトルは 10px UC の SOURCE / MONITOR / INSPECTOR / CONSOLE、影ゼロ、フラット単色プログレス、動きは実行中ドット1点のみ。バージョン19まで熟成したソフトウェアが持つ「何も証明しようとしない」佇まいを再現しています。

## Distinct from a generic dark theme

汎用ダークテーマは「黒くした Web ページ」— 本案は温度統一された3段サーフェス、ヘアライン+サーフェス差の二重分離、機能限定アクセント、EN マイクロラベル規律、全数値の等幅 tabular、状態のエッジマーカー表現という NLE 固有の文法で組んであり、スクリーンショット単体で商用スイートの1画面として通用することを合格基準にしています。
