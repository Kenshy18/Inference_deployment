# Production minimum-Recall experiment (2026-08-08)

No video frame was opened.  All evaluation used polygon geometry stored in
SQLite.

## Controlled input

- Source: `data/12月KPI動画.sqlite`
- Label: `男性器`
- Frames: `8681..20059`
- Baseline: Production v22, requested interval 10
- Recall floor: `0.97`

## Result

Two interpretations of "change mean Recall to minimum Recall" were tested.

### Direct internal budget replacement

The Production DP budget was changed from accumulated `1 - Recall` with an
average allowance to accumulated per-frame deficits
`max(0.97 - Recall, 0)` with zero allowance.  Candidate generation, pair-vote,
and exact repair remained Production implementations.

This was not a valid final solution:

- keyframes: `664 -> 667`
- minimum Recall: `0.0560 -> 0.6991`
- violations: `1814 -> 39`
- mean IoU: `0.8822 -> 0.6668`
- mean area ratio: `1.1113 -> 1.5994`
- optimizer time: `85.61 -> 154.96 sec`

The fixed candidate/repair machinery tried to satisfy the stronger constraint
mostly by expanding existing shapes.  It neither eliminated every violation
nor preserved IoU.

Report:
`output/production_min_recall_20260808/full_male_interval10/comparison.json`

### Production-preserving local minimum-Recall guard

All Production keyframes were retained.  Each Production interval was tested
with exact interpolation semantics.  The local DP inserted the fewest raw
anchors required to satisfy the floor, using IoU only as the second tie-break.

- keyframes: `664 -> 1445`
- actual mean interval: `10.3495 -> 4.6533`
- added keys: `781`
- adjusted Production anchors: `116`
- minimum Recall: `0.8064 -> 0.9720`
- violations: `989 -> 0`
- Recall q1: `0.8946 -> 0.9725`
- mean IoU: `0.8871 -> 0.9398`
- IoU q1: `0.6672 -> 0.7678`
- mean area ratio: `1.0868 -> 1.0359`
- area-ratio q99: `1.3978 -> 1.2944`
- optimizer time: `68.43 sec` (`82.13 sec` complete wall time)
- SQLite integrity: `ok`
- foreign-key errors: `0`
- schema fingerprint: identical to the baseline

This version enforces minimum Recall without the direct replacement's global
inflation failure, but it demonstrates that `0.97` on every raw observation is
expensive: the effective key interval falls from about 10.35 to 4.65.

Report:
`output/production_min_recall_20260808/production_guard_interval10/comparison_report.json`

Deliverable SQLite:
`output/production_min_recall_20260808/production_guard_interval10/12月KPI動画_旧Production最小Recall097_目標間隔10.sqlite`

## Conclusion

Production plus an exact minimum-Recall guard is technically feasible and
retains Production's interpolation behavior, but it is not a free one-line
upgrade.  A hard floor against every raw mask requires substantially more
keys.  The direct budget substitution must not be promoted.  The local guard
is the valid experimental reference for visual review.
