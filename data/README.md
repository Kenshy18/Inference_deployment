# Data handling policy

このディレクトリ以下の動画と、それらから生成したフレーム画像は機密データとして扱う。

- 動画、フレーム画像、プレビュー、コンタクトシートを外部サービス、API、プロキシ、インターネットへ送信しない。
- AIエージェントは動画フレームまたはフレーム画像を直接読み込み、表示、スクリーンショット化、画像入力として取り込まない。
- 動画のデコード、推論、後処理、数値解析は、このPC内で完結するローカルプロセスとしてのみ実行できる。
- AIエージェントが確認できる対象は、動画のメタデータ、処理ログ、SQLite、マスク座標・形状データ、集計済み数値指標に限定する。
- マスクや検出結果を確認するときも、元フレームを合成した画像や動画をAIエージェントへ渡さない。
- 調査用の派生成果物はローカルの無視対象ディレクトリへ保存し、明示的な許可なしに共有・Pushしない。
- 使用するツールがネットワーク送信を伴わないことを確認し、不明な場合は実行しない。

この方針は、このディレクトリのすべてのサブディレクトリと、ここにある動画から派生したデータに適用する。
